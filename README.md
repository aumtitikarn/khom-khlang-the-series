# khom-khlang-the-series

เว็บ 3D diorama แฟนเมดจากซีรีส์ ข่มขลัง (Khom Khlang The Series)
สร้างด้วย React Three Fiber · 5 ฉากอินเทอร์แอกทีฟ หมุนดู ซูม และกดหมุดดูตัวละครได้

## Build

```bash
npm install
node build.mjs
# ได้ไฟล์ dist/khom-diorama.html เปิดในเบราว์เซอร์ได้เลย
```

> แฟนเมด ไม่ใช่ของทางการ ลิขสิทธิ์ซีรีส์เป็นของ WeTV และ Star Hunter Entertainment
